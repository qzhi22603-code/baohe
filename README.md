# 宝盒（baohe.localhost.cc）

一个本地优先的任务打卡集卡小站。无需登录，所有数据保存在浏览器 `localStorage` 中；
网站更新只修改代码，不会触碰用户存储，数据不会丢失。

## 页面

| 页面 | 说明 |
|------|------|
| 今日任务 | 把任务卡片**拖进**右侧清单（或点卡片右上角 ＋），完成后点击方块打勾，即可收集卡片；卡片按类别筛选（学习/体育/文艺/生活/其他） |
| 卡片盒 | 查看收集到的卡片与数量（如：跑步 ×8）、类别标签、累计统计 |
| 成就 | 10 个成就，系统自动判定解锁（金光闪闪、开门大吉、初入宝盒、百尺竿头、七日之约、一键三连、未雨绸缪、断舍离、金石为开、满堂彩） |
| 公告板 | 网站更新记录（当前 v1.1.0） |
| 关于作者 | Quanzhi · 一个有点天才的天才 · 微信号 `_Quanzhi` |
| 设置 | 四套配色（浅蓝白 / 黑白 / 橙白 / 粉白）、数据导出导入清空 |

## 本地运行

需要通过 HTTP 访问（不要直接双击打开文件）：

```bash
cd baohe
python -m http.server 8123
# 然后浏览器打开 http://localhost:8123
```

若 `*.localhost.cc` 已解析到 127.0.0.1（通配符本地域名），也可用
`http://baohe.localhost.cc:8123` 访问，效果相同。

## 部署到公网（让任何电脑都能访问）

纯静态站点，随便托管到哪儿都行，常见选择：

- **GitHub Pages**：把仓库推到 GitHub，Settings → Pages → 选择分支即可，得到
  `https://<用户名>.github.io/<仓库名>/`
- **Vercel / Netlify / Cloudflare Pages**：导入仓库，零配置自动构建

> 注意：数据按「域名 + 浏览器」隔离。换域名或换浏览器后数据不共享，
> 可在 设置 → 导出/导入数据 中搬移。

## 后续维护指南（给作者）

- **添加内置任务卡片**：编辑 `js/app.js` 顶部的 `BUILTIN_CARDS` 数组（`cat` 取值 study/sport/art/life/other）。
- **添加成就**：编辑 `ACHIEVEMENTS` 数组（格式见注释）。
- **发布更新公告**：在 `ANNOUNCEMENTS` 数组最上方追加一条，用户导航上会出现红点提示。
- **更换作者头像**：把微信头像图片放到 `assets/avatar.jpg`（文件名固定），自动生效。
